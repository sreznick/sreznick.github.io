Когда скрытая единица исчезает

Нормальные:    (−1)^S × 1.M × 2^(E − 127)
Субнормальные: (−1)^S × 0.M × 2^−126

E = 0, дробная часть M ≠ 0
Порядок для масштаба: −126, а не −127.
Минимальный шаг: 2^−23 × 2^−126 = 2^−149
Денормализованные и субнормальные — два названия одной категории.

Стык без разрыва

0x007FFFFF = 2^−126 − 2^−149  (наибольшее субнормальное)

0x00800001 = 2^−126 + 2^−149  (следующее нормальное)

Точность возле нуля

  • В субнормальной области абсолютный шаг постоянен: 2⁻¹⁴⁹.

#include <stddef.h>

void add_avx(const float *a, const float *b,
             float *c, size_t n) {

        __m256 x = _mm256_loadu_ps(a + i);
        __m256 y = _mm256_loadu_ps(b + i);

Измерение без самообмана

  • Проверить результат до измерений.
  • Убрать выделение памяти и печать из измеряемого участка.
  • Прогреть код, повторить замер, показать разброс.
  • Использовать результат, чтобы вычисление не исчезло.
  • Зафиксировать CPU, размер данных, компилятор и флаги.
Если сравниваете со скалярным кодом, убедитесь по ассемблеру, что эталон сам не векторизован.
